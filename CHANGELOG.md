# Changelog

## 0.2.0

- Add a native menu bar status icon.
- Show full-performance, pending, low-power, paused, and error states.
- Add manual Low Power Mode controls and a session-local pause switch.
- Add shortcuts to the local log and project page.
- Keep the status UI event-driven with no repeating polling timer.

## 0.1.0

- Initial automatic lock/display-sleep Low Power Mode switching.
- Add a scoped two-command sudoers rule, installer, uninstaller, status tool,
  tests, and bilingual documentation.
